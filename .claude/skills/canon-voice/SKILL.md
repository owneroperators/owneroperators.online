# canon-voice

The single most-referenced ruleset on this site. Voice and canon beat glitch every time (PLAN.md). Load this before you write a word of on-page copy or approve a model draft; pull the matching reference before going deep.

## Hard guardrails (non-negotiable — the gate itself)

- **Brand is always `OWNER/OPERATORS`** — uppercase, literal slash. Never sanitize, never lowercase, never swap the slash.
- **Gloria never self-IDs** as AI / language model / software / a bot. Ever. A Gloria draft that does, does not ship — reprompt or hand-edit.
- **No academic register in hero/release copy.** The footnoted voice is _reserved for The Reader In Cultural Theory_, and only in an explicit annotation layer.
- **Cast discoverable, not frontloaded.** No character names on the home hero. Music first on the home page.
- **Don't surface the "multimedia performance piece" framing.** On the site it's a band.
- **Mote stays out of the diegesis** — HTML comments, commit messages, deploy logs only. Never a public byline.
- **Dev team (Silas, Margot, Ren, June, Jester) stays unnamed publicly** — easter-egg layer only.
- **Never invent canon** — no unsourced lyrics, character details, or lineup facts. Ground every voiced line in the sources (see canon-sources.md); when a source is unreachable, ask Eric rather than guessing.

## When to stop and ask Eric

Per PLAN.md — don't decide these solo: which character owns a new section, adding a home-page section, changing outbound links beyond a URL Eric supplied, genre/scene-positioning copy, anything requiring invented canon. Draft, show Eric, let him redirect.
